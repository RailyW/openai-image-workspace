# 历史功能

历史功能展示 IndexedDB 中的成功和失败任务，并提供删除和清理。

## 界面

页面使用 shadcn 风格的卡片、按钮和状态标记展示任务。清理操作统一使用带图标的按钮，任务状态使用 `Badge` 标记。

## 规则

- 成功任务可关联本地图片。
- 失败任务只保存参数和错误摘要。
- 任务历史不保存 Bearer Token。

## 文件说明

- `HistoryPage.tsx`：读取本地任务和图片，展示任务参数快照、图片缩略图和清理入口。
- `historyActions.ts`：封装删除任务、按状态清理任务、只清理图片等 IndexedDB 操作。
